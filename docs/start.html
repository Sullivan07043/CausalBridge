Get started

Four commands to your first names

You need Linux on x86_64 and an NVIDIA GPU with its driver. The installer puts CausalBridge in its own environment and does not touch your Python.

1Install

Downloads the release, checks its SHA256 sum and installs the causalbridge command.

curl -fsSL https://raw.githubusercontent.com/Sullivan07043/CausalBridge/main/install.sh | sh

2Check

Shows the GPU, the profiles and whether your language model is compatible.

causalbridge check

3Get a language model

Download the model you want. Or skip this step and use a hosted API.

~/.local/lib/causalbridge/current/bin/hf download Qwen/Qwen3-4B-Instruct-2507

4Name

Give the data and the names you know. The first run downloads the example profile.

causalbridge name data.csv --names names.csv --out result
