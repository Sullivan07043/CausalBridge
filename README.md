# CausalBridge has moved

CausalBridge is now open source under the Apache License 2.0 at
**https://github.com/causal-intelligence/causal-bridge** and installs with

```sh
pip install causal-bridge
```

Project page: https://causal-intelligence.github.io/causal-bridge/

This repository held the earlier closed releases (0.1.0 to 0.2.3) and is kept
for their download links only. New issues and contributions go to the new repository.
